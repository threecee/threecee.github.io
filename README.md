# threecee.github.io

User documentation for threecee personal iOS apps:

- **HealthInsights** — diabetes data + insights for personal use.
- **MyLoop With Watch** — personal Loop fork with Apple Watch companion.

Live at: https://threecee.github.io/

The site is rendered by GitHub Pages from markdown source. Edit the
`*.md` files at the repo root and push to `main` — the site rebuilds
automatically.

Privacy policies live in separate repos:

- https://github.com/threecee/healthinsights-privacy → https://threecee.github.io/healthinsights-privacy/
- https://github.com/threecee/loop-privacy → https://threecee.github.io/loop-privacy/
